FAQ

Frequently Asked Questions

What is ProViz? ▼

ProViz is an interactive 3D web platform that visualizes Python code execution, array modifications, vector mathematics, and equations step-by-step using Three.js and Pyodide WebAssembly.

Do I need to install Python locally? ▼

No! ProViz uses Pyodide, which runs full Python 3 inside your browser client-side using WebAssembly technology.

Who can log in to ProViz? ▼

Students and educators can log in using Google Sign-In with their university or personal email addresses.

Is ProViz free to use? ▼

Yes, ProViz is 100% free for students, TAs, and learners interested in 3D Python math visualization.
