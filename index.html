Features

A debugger that shows its work.

ProViz records everything your program does, so you can explore it like a timeline instead of guessing from print statements.

Time-travel debugging

Step over, into and out of calls — then step backwards. Scrub the timeline to any moment and the whole program state follows.

A live 3D memory world

Call frames, variables, lists, dictionaries and objects are laid out in space and glide to their new state with every step.

References you can see

Aliasing stops being a mystery: two names pointing at one list draw two arcs landing on the same object.

Breakpoints & inline values

Click the gutter to set a breakpoint, continue to it, and read changed values right at the end of each line.

Plain-English explanations

Every step is narrated — what changed, which function was called, what was returned — so beginners never feel lost.

A sandbox that can't hang

Infinite loops and runaway recursion are stopped safely, and errors arrive as clear cards that point to the exact line.

FAQ

Questions, answered.

Do I need an account?

No. Choose “Try without signing in” to use the Visualizer straight away. Signing in with any Google account keeps your preferences and role, so developer accounts get their studios automatically.

Which languages are supported?

ProViz currently supports Python — standard CPython compiled to WebAssembly, including the standard library. Java, C++ and JavaScript are planned for future updates. Interactive input() is not supported yet.

Is my code uploaded anywhere?

No. Execution and tracing happen locally in your browser tab. The only network requests are for the language runtime, fonts and, if you sign in, Google authentication.

What happens if my program loops forever?

ProViz stops execution safely after a step and time budget, then lets you inspect everything that happened up to that point.

What is developer access?

Developer access (Admin and Super admin) is reserved for the team that builds and operates ProViz. Everyone else gets general access, which includes the complete Visualizer and debugger.
